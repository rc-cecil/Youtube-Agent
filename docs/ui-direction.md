# UI redesign brief

Scope: existing Phase 1 web app, plus user-approved future-feature previews. Operate mode. Direct code implementation was explicitly selected by the user. Efferd references inform hierarchy only; no demo dashboard or duplicate hero is rendered.

## Direction contract

THESIS: a creator's footage desk, with originals and their ingestion state at the center.

OWN-WORLD: graphite equipment surfaces, readable warm-white type, lime action keys, squared media framing, and compact list rows.

STORY: see the recording workflow, upload original footage, track validation, find files again. Future features are labeled previews.

FIRST VIEWPORT: a compact left navigation rail; workspace title; one wide hero with copy left and supplied animated phone footage right; an understated strip of real library totals below. Pause/play is the signature interaction. Small actions use fast, shared motion tokens.

FORM: source-footage desk, candidate 4, seed 27da0a10. The user-provided video and requested compatible Efferd structure constrain the design.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.

## Considered structures

1. Edit-bay workspace. 2. Recording contact sheet. 3. Broadcast rundown. 4. Source-footage desk. 5. Capture-device control panel. 6. Tournament replay library. 7. Production handoff ledger.

The reference suggestions were evaluated against audience identification and task clarity. Darkroom overlays obscure status; rhythm-machine keys imply controls not available; material inventory metaphors misrepresent the workflow. Their useful disciplines are tonal separation, clear state contrast, and consistent file labeling—not decorative copies. The existing API and navigation remain authoritative.
