# Efferd reference blocks

Source: `https://efferd.com/r/{style}/{name}.json`, resolved by the shadcn CLI with the project's Radix Nova style.

Installed blocks: `@efferd/hero-2` and `@efferd/dashboard-4`.

The user explicitly requested reference-only adaptation, not replicas. Original demo-specific files were moved here after installation and given `.txt` extensions so they cannot become application routes or bundled components. Shared shadcn primitives remain in the web application. No demo revenue, brand logos, sample user accounts, or duplicate hero/dashboard is presented in the product.

These files retain upstream source for traceability. Do not import them into the app or treat their placeholder links/data as product requirements.
