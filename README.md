# AI Gameplay Shorts Agent

An autonomous AI-powered content creation and publishing system that turns long-form gameplay recordings into high-quality YouTube Shorts.

The system analyzes uploaded gameplay, detects interesting game-specific moments, selects the strongest clips, creates aggressively edited vertical Shorts with Remotion, generates titles and hashtags, schedules three different Shorts per day, publishes them to YouTube, tracks performance and revenue, and learns what types of content perform best over time.

---

Overview

The AI Gameplay Shorts Agent is designed to function like an autonomous gaming content team.

Instead of manually:

- watching hours of gameplay,
- finding highlights,
- cutting clips,
- converting them to vertical video,
- adding captions,
- creating titles,
- selecting hashtags,
- uploading to YouTube,
- scheduling posts,
- checking analytics,
- and deciding what content to make next,

the system automates the majority of the workflow.

The intended workflow is:

```text
Upload Gameplay
      ↓
Gameplay Analysis
      ↓
Game Detection
      ↓
Highlight Detection
      ↓
AI Ranking

      ↓
Remotion Rendering
      ↓
Quality Control
      ↓
YouTube Scheduling
      ↓
Publishing
      ↓
Analytics Collection
      ↓
